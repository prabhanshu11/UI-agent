What is this page

Visual regression testing for waybar status bar icons. Claude Haiku 4.5 analyzes screenshots to verify all expected icons are visible (microphone, clipboard, keyboard layout, bluetooth, wifi, volume, power-profile). Tests run inside Docker containers with host Wayland socket bindings.
  • OK — Vision model's assessment is correct
  • Wrong — Vision model made an error (false positive/negative)

Filters

  • All: every test result
  • Passed: tests where all icons were found
  • Failed: tests with missing icons
  • Unreviewed: results without human review

Keyboard Shortcuts

  • J/K — navigate rows
  • 1 — mark OK
  • 2 — mark Wrong
  • Space — expand details
